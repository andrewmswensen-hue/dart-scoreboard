# Manually recorded matches

Matches played before result uploads were set up, transcribed from the app's match
summary screens on 2026-09-29. The columns match the Google Sheet tabs the upload
script creates (`Matches` and `Player results`), so these rows can be pasted in directly.

- Finish times were not on the screenshots; the start time is in the match data column.
- Checkout % was not shown, so it is blank.
- Busts are summed from the per-leg bust counts. Locks count manual Lock In only; auto-locks
  are in the match data text.
- 100+ counts were 0 for everyone in both matches.
